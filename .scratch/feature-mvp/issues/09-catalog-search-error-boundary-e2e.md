# 09 — 算法目录搜索、局部错误边界降级与端到端集成测试

**What to build:**
算法学习者可以在侧边栏/主页通过中英文搜索关键词（如“冒泡”、“BFS”、“DP”、“二分”）快速过滤算法；如果画布在极端异常输入下渲染失败，局部错误边界（Local Error Boundary）将自动降级为文本步骤面板，而不影响代码与全局导航；系统通过完整的端到端集成测试与多主题视觉回归测试，确保 MVP 六大基准算法高质量交付。

**Blocked by:** 06 — 堆排序双场景联动演示 (Array + Binary Tree), 08 — 棋盘回溯渲染器与 N 皇后算法

**Status:** ready-for-agent

- [ ] 在 `apps/web` 中实现算法目录搜索（按中英文名称、标签、数据结构类型过滤）与空状态提示。
- [ ] 实现画布区域的 `LocalErrorBoundary` 组件，当渲染器崩溃时优雅降级并提供“重置数据”按钮。
- [ ] 编写 Playwright 端到端自动化测试，覆盖 6 个基准算法的目录进入、播放、暂停、单步、调速、输入修改与 URL 分享全流程。
- [ ] 统一进行浅色/深色主题、移动端触摸布局适配与 Reduced Motion 视觉回归验收。
