# Hello Algo Interactive

基于《Hello 算法》内容资产的高质量交互式算法演示与学习平台。

## 🌟 项目亮点

- **统一语义事件引擎**：纯函数式算法打点（Semantic Events），状态由不可变快照（State Snapshots）严格驱动，Seek 与反向回退零延迟、零错乱。
- **空间连续动画**：基于 Motion layout 与专用动效配方（Motion Recipe），赋予数据元素稳定 Entity ID，告别快照式生硬重建。
- **多语言代码同步**：通过抽象语义锚点（Semantic Code Anchors）无缝联动 TypeScript / Go / Rust 等多语言代码行高亮与实时变量看板。
- **多渲染器复合场景**：Sequence、Linked、Graph/Tree (React Flow)、Grid/Board (CSS Grid) 协同驱动。
- **现代设计系统**：基于 shadcn/ui 与 Tailwind CSS，支持深浅主题 OKLCH 语义色盘与 Reduced Motion 无障碍体验。
- **无状态 URL 分享**：确定性 PRNG（Mulberry32）支持任意算法自定义输入与随机示例的一键分享与 100% 精确复现。
